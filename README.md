# SalesPulse

Мгновенная **аналитика продаж** из CSV-выгрузки (1С, CRM, Excel-экспорт) без Power BI и сводных таблиц. Одна команда — и у руководителя продаж готовый отчёт: выручка, средний чек, топ товаров и категорий, динамика по месяцам и ABC-анализ ассортимента.

Если своего файла нет, программа сама сгенерирует детерминированный демо-набор на 500 продаж — можно оценить отчёт сразу после клонирования.

## Идея проекта

Классическая ситуация: данные о продажах есть в виде выгрузки, а ответ на вопрос «что у нас вообще продаётся?» требует Excel и получаса времени. SalesPulse отвечает за секунды и сразу считает то, что в Excel делается вручную и редко:

| Отчёт | Управленческий вопрос |
|---|---|
| Топ-5 товаров и категорий | на чём зарабатываем |
| Динамика по месяцам | растём или падаем, есть ли сезонность |
| **ABC-анализ** | какие товары дают 80% выручки — и не тащим ли мы мёртвый ассортимент |
| Средний чек | базовая единица экономики |

## Формат данных

CSV с заголовком, разделитель `;`:

```
date;product;category;qty;price
2026-03-14;Ноутбук Pro 15;Электроника;2;129990
```

Дата — в формате ISO `гггг-мм-дд` (месяц для группировки берётся из первых 7 символов). Цена допускает и точку, и запятую в дробной части. Битые строки пропускаются и не роняют отчёт.

## Быстрый старт

Нужны **JDK 17+** и **Scala 3** через [scala-cli](https://scala-cli.virtuslab.org/) (`winget install VirtusLab.ScalaCLI`). Зависимостей нет — только стандартная библиотека.

```bash
git clone https://github.com/KorolKiraA/sales-pulse.git
cd sales-pulse

scala-cli run SalesPulse.scala              # демо-набор на 500 продаж
scala-cli run SalesPulse.scala -- sales.csv # свои данные
```

Первый запуск scala-cli скачает компилятор Scala 3 — займёт пару минут, дальше запуски быстрые.

```
  3. Стол Loft             6 986 590,00
  4. Монитор 27"           5 318 480,00
  5. Наушники ANC          4 723 110,00

--- Динамика по месяцам ---
  2026-01 | ███████████████████████████████████████ 6 866 310
  2026-03 | ████████████████████████████████████████ 6 892 240
  ...

```

## ABC-анализ

Товары сортируются по выручке, после чего идёт накопительный подсчёт, пока сумма не достигнет 80% общей выручки. Попавшие в эту границу товары — **класс A**: ядро ассортимента, которое нельзя терять с полки. Остальные делятся на B (середина) и C (длинный хвост).

Интерпретация: если класс A — это 50% ассортимента (как в демо), портфель сбалансирован. Если 10% — бизнес держится на паре товаров, и их сток-аут критичен.

## Как это устроено

```
sales-pulse/
├── SalesPulse.scala      # парсинг, аналитика, ABC, генератор демо
├── .github/workflows/ci.yml  # компиляция на каждый push
├── LICENSE
└── README.md
```

**Ключевые решения в коде:**

- `case class Sale` + `Option` при парсинге: битая строка превращается в `None` и отбрасывается через `flatMap`, а не в исключение;
- вся аналитика — `groupBy(...).view.mapValues(...)`: `view` не материализует промежуточные коллекции;
- генератор демо использует фиксированный seed (`new Random(42)`), поэтому демо-отчёт воспроизводим и его можно сравнивать между запусками;
- гистограмма нормируется на максимум: самый прибыльный месяц — всегда 40 символов.

## Проектные решения и ограничения

- **Файл читается целиком в память.** Для выгрузок до сотен тысяч строк это нормально; на миллионах нужен потоковый обход итератором.
- **Разделитель только `;`.** Выгрузка с запятыми (английский Excel) не распознается — осознанный выбор под русскую локаль, где `;` стандарт.
- **Доходность не считается**: в данных нет себестоимости, только цена продажи. «Выручка» здесь — оборот, а не прибыль.
- **Категории берутся из файла как есть**: опечатка `Электоника` создаст отдельную категорию. Дедупликация справочников — на стороне источника.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `Нет данных. Проверьте формат CSV` | файл не в формате `date;product;category;qty;price` или путь указан неверно; заголовок обязателен |
| Крякозябры вместо кириллицы | запускайте в Windows Terminal, либо `chcp 65001` перед запуском; CSV должен быть в UTF-8 |
| `scala-cli: команда не найдена` | `winget install VirtusLab.ScalaCLI`, затем переоткрыть терминал |
| Первый запуск долгий | scala-cli скачивает компилятор — это разовая операция |
| Числа съехали | CSV в кодировке не UTF-8 (например, windows-1251 из 1С): пересохраните файл в UTF-8 |

## Идеи для развития

- потоковое чтение больших файлов итератором;
- сравнение периодов (месяц к месяцу, год к году) с процентами роста;
- экспорт отчёта в HTML/PDF одним файлом;
- чтение напрямую из Excel (.xlsx) без промежуточного CSV;
- прогноз следующего месяца простым скользящим средним.
